# Cosmos — Interface inicial

Protótipo da interface Overview do Cosmos, uma experiência de exploração espacial.

## Executar
Abra `index.html` no navegador. Para publicar, envie os arquivos para um repositório GitHub e habilite GitHub Pages.

## Nesta versão
- Layout responsivo
- Navegação lateral adaptável
- Dashboard visual
- Ilustração CSS do planeta e Sistema Solar
- Cards de progresso e missões de demonstração
